# SUS - Evaluacion de Usabilidad

## Objetivo
Preparar el instrumento SUS para evaluar la usabilidad percibida del prototipo con participantes reales. No se reportan resultados SUS hasta contar con respuestas reales de participantes.

## Perfil de participantes
Participantes sugeridos:

- coordinador academico;
- responsable de horarios;
- docente;
- personal de registro academico;
- estudiante o usuario observador del proceso academico.

Cantidad minima sugerida: 5 participantes. Ideal: 8 a 12 participantes para obtener una lectura mas estable.

## Tareas sugeridas
Antes de responder SUS, cada participante deberia intentar:

1. Navegar al panel principal.
2. Crear o revisar un periodo academico.
3. Registrar o revisar docentes.
4. Registrar o revisar aulas.
5. Registrar o revisar cursos.
6. Revisar grupos/secciones.
7. Generar o revisar el horario.
8. Interpretar la grilla de horarios.

## Preguntas SUS
Escala Likert:

1 = Totalmente en desacuerdo  
2 = En desacuerdo  
3 = Neutral  
4 = De acuerdo  
5 = Totalmente de acuerdo

| Nro | Pregunta | Respuesta 1-5 |
|---|---|---|
| 1 | Creo que me gustaria usar este sistema con frecuencia. | |
| 2 | Encontre el sistema innecesariamente complejo. | |
| 3 | Pense que el sistema era facil de usar. | |
| 4 | Creo que necesitaria ayuda de una persona tecnica para poder usar este sistema. | |
| 5 | Encontre que las funciones del sistema estaban bien integradas. | |
| 6 | Pense que habia demasiada inconsistencia en el sistema. | |
| 7 | Imagino que la mayoria de personas aprenderia a usar este sistema rapidamente. | |
| 8 | Encontre el sistema dificil de usar. | |
| 9 | Me senti seguro usando el sistema. | |
| 10 | Necesite aprender muchas cosas antes de poder usar el sistema. | |

## Formula de calculo

- Items impares: `respuesta - 1`.
- Items pares: `5 - respuesta`.
- Sumar los 10 valores ajustados.
- Puntaje SUS final: `suma total * 2.5`.
