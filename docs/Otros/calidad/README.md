# Calidad AT002

Esta carpeta consolida la preparacion tecnica para la tarea **AT002: Revision de codigo con SonarQube**.

El objetivo es reunir configuracion, procedimientos, resultados reales y pendientes relacionados con SonarQube, OWASP, WCAG, SUS, pruebas automatizadas y cobertura.

## Documentos

| Documento | Proposito | Estado |
|---|---|---|
| [01_sonarqube.md](01_sonarqube.md) | Configuracion y procedimiento para analisis SonarQube. | Configurado; ejecucion real pendiente. |
| [02_owasp.md](02_owasp.md) | Matriz inicial de riesgos OWASP basada en el codigo actual. | Diagnostico inicial. |
| [03_wcag.md](03_wcag.md) | Checklist inicial WCAG para frontend. | Pendiente de validacion con Lighthouse/axe. |

| [05_testing_y_cobertura.md](05_testing_y_cobertura.md) | Estado de pruebas y cobertura. | Contiene ejecuciones reales de esta fase. |
| [06_plan_mejoras.md](06_plan_mejoras.md) | Plan priorizado de mejoras de calidad. | Propuesto. |

## Criterio de evidencia

- No se reportan metricas SonarQube sin ejecutar el analisis real.
- No se reportan puntajes SUS sin respuestas reales de participantes.
- No se reportan porcentajes de cobertura no generados por herramientas.
- Las limitaciones de entorno se documentan como pendientes, no como resultados exitosos.
