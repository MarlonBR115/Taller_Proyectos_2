# Documentacion de Cierre

Esta carpeta consolida la evaluacion final del proyecto, las lecciones aprendidas, la revision del acta, la declaracion de trabajo y el mapa de cumplimiento de la rubrica.

| Documento | Proposito | Estado |
|---|---|---|
| [01 - Informe Final](01_Informe_Final_Proyecto.md) | Consolida alcance, plan vs ejecucion, metricas y entregables. | Completo documentalmente |
| [02 - Lecciones Aprendidas](02_Lecciones_Aprendidas.md) | Registra aprendizajes y recomendaciones futuras. | Completo |
| [03 - Acta Revisada](03_Acta_Constitucion_Revisada.md) | Evalua criterios iniciales desde la perspectiva de cierre. | Completo documentalmente |
| [04 - Declaracion de Trabajo SOW](04_Declaracion_Trabajo_SOW.md) | Verifica trabajo, exclusiones y criterios de aceptacion. | Completo |
| [05 - Checklist Sobresaliente](05_Checklist_Cierre_Sobresaliente.md) | Mapea la rubrica con evidencia del repositorio. | Completo; requiere validacion final |
