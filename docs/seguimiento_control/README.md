# Documentacion de Seguimiento y Control

Esta carpeta agrupa documentos de monitoreo del proyecto, gestion de riesgos, impedimentos y estado de sprints. Su objetivo es mantener trazabilidad academica entre avances, riesgos, evidencias y decisiones del equipo.

## Registros de gestion

| Documento | Proposito | Estado |
|---|---|---|
| [Registro de Riesgos y Oportunidades](01_Registro_de_Riesgos_y_Oportunidades.md) | Identifica riesgos tecnicos, operativos y oportunidades de mejora para el prototipo de horarios. | Referencia principal para A004-03. |
| [KPI y Metricas](02_KPI_y_Metricas.md) | Define KPI implementados, parciales y propuestos para calidad de horarios y proceso academico. | Referencia principal de metricas de seguimiento. |
| [Trazabilidad Jira/GitHub](03_Trazabilidad_Jira_GitHub.md) | Relaciona tareas, archivos, evidencias, pruebas, metricas y riesgos. | Base de trazabilidad; PR y ramas pendientes si no existen. |
| [Registro vigente de Impedimentos](04_Registro_de_Impedimentos.md) | Registra obstaculos actuales, responsables y acciones de desbloqueo. | Referencia principal para A005. |
| [Registro de Incidentes](05_Registro_de_Incidentes.md) | Consolida problemas reales ocurridos durante la ejecucion. | Vigente para cierre. |
| [Registro de Defectos](06_Registro_de_Defectos.md) | Registra defectos tecnicos y documentales, corregidos o pendientes. | Vigente para cierre. |
| [Registro de Supuestos](07_Registro_de_Supuestos.md) | Controla condiciones asumidas para el prototipo. | Vigente para cierre. |
| [Registro historico de Impedimentos](02_Registro_de_Impedimentos.md) | Conserva impedimentos registrados en etapas anteriores. | Historico; no reemplaza el registro vigente. |

## Pendientes documentales recomendados

- Completar ramas, commits y PR reales en la trazabilidad cuando existan.
- Persistir metricas/KPI de generacion y validacion cuando el backend incorpore historico por corrida.
- Actualizar informes de sprint posteriores sin sobrescribir documentos historicos.
- Mantener incidentes, defectos y supuestos vinculados con Jira, riesgos e impedimentos.
