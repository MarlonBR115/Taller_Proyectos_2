# Documentacion de Capacitacion

## Objetivo

Proporcionar una ruta de aprendizaje para comprender, ejecutar, operar y mantener el prototipo sin depender exclusivamente del conocimiento de sus autores originales.

## Publico objetivo

- equipo de desarrollo;
- Scrum Master;
- responsables academicos;
- futuros mantenedores;
- evaluadores del proyecto.

## Orden recomendado

1. Leer la [vision general](../01_vision_general.md) y el [mapa del proceso academico](../02_mapa_proceso_academico.md).
2. Revisar esta guia de instalacion.
3. Estudiar backend/API o operacion academica segun el rol.
4. Revisar pruebas, calidad y mantenimiento.
5. Consultar impedimentos, riesgos y SDD antes de proponer cambios.

## Conocimientos previos

Para operar el prototipo se requiere comprender el proceso academico basico y los datos de cursos, docentes, aulas, periodos y grupos. Para mantenerlo se recomienda experiencia basica con Git, Node.js, npm, React, Express y MySQL.
